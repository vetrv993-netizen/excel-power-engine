# v0.10 — الذكاء الموحد والعمليات المتحققة

## الجلسة المركزية

`WorkbookSession` هو نقطة الدخول الموحدة للمصنف: يحتفظ بمسار المصدر وبصمته،
وسياق المصنف، والمقترحات، وخط أساس أخطاء الصيغ، ومجموعات نتائج البحث والأهداف،
وسجل المعاملة. إذا تغير المصدر بعد إنشاء الجلسة ترفض العملية التنفيذ بدلاً من
العمل على تحليل قديم.

## البحث إلى الهدف

تسجل عملية `search` `SearchResultSet`. كل مجموعة يمكن تحويلها إلى `TargetSet`
مع إزالة التكرارات وتجميع الخلايا حسب الورقة وحفظ provenance. تضع العملية التالية
`target_set` و`selected_hits` لاستخدام النتائج المختارة بدلاً من نطاق يدوي.

## keyed-bulk

`keyed-bulk` يطابق سجلات المصدر بعمود وجهة. السياسة الافتراضية `reject`: تمنع
أي كتابة عند missing keys أو duplicate source/target keys. يمكن اختيار `skip`
للمفاتيح المفقودة صراحةً؛ تبقى المفاتيح المكررة خطأ يجب مراجعته.

## بوابة التحقق

كل تعديل في Workspace يعمل على staging ثم يخضع إلى `VerificationResult`:

1. وجود output وقراءته كحزمة OOXML.
2. مقارنة القيم أو الصيغ المستهدفة.
3. مقارنة أخطاء الصيغ قبل/بعد ومنع الأخطاء الجديدة.
4. فحص ثبات VBA ووجود امتدادات x14/x15 إن وجدت في المصدر.
5. مقارنة changed parts مع allow-list العملية.

لا يُنسخ الناتج النهائي إذا فشلت البوابة. يكتب Workspace manifest دائمًا بجانب
الناتج، ويستخدم rollback مسار backup المسجل فيه.

## التحقق البصري

`visual_policy=optional` يسجل محاولة فتح Excel. `required` يرفض completion إن
لم ينجح فتح Excel وتحديد الهدف؛ ويحتاج Windows وExcel desktop.
