# واجهة v0.5 العربية

## الوظائف
- اختيار ملف XLSX/XLSM وعرض أوراقه.
- فحص سريع وفحص عميق دون حفظ المصنف.
- معاينة ورقة مباشرة من OOXML بدون OpenPyXL في مسار العرض.
- Safe/Smart Edit لقيمة أو صيغة.
- فتح Excel بصريًا والانتقال للورقة والخلية المعدلة.
- سجل تدقيق محلي JSONL.

## التشغيل
```powershell
.\.venv\Scripts\python.exe -m excel_power_engine.gui
```
أو:
```powershell
.\scripts\run_cli.ps1 -Command gui
```
