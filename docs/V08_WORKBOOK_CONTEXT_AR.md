# v0.8 — سياق المصنف الذكي

يضيف v0.8 طبقة مركزية لفهم المصنف عند إدراجه بدل إعادة ضبط الإعدادات يدويًا في كل تبويب.

## ما يتم اكتشافه تلقائيًا

- الأوراق والنطاق المستخدم.
- صف العناوين المحتمل.
- بداية ونهاية البيانات.
- أسماء الحقول وأعمدتها.
- نوع الحقل التقريبي: نص، رقم، تاريخ، صيغة.
- أمثلة من الصفوف.
- الخلايا ذات الصيغ والقيم.
- الحماية والدمج.
- الألوان الغالبة للملء والخط كمقترحات.
- نطاقات مقترحة للاستخدام في الإدخال والعمليات.
- خريطة الحقول Field Map لاستخدامها في الإدخال والبحث.
- أوراق مقترحة للاستخدام حسب كثافة البيانات.

## تكامل الواجهة

عند إدراج ملف:

`اختيار الملف → تحليل المصنف → بناء السياق → تطبيق المقترحات`

ويتم تلقائيًا تعبئة أو اقتراح:

- الورقة الحالية.
- الخلية المركزية للمعاينة وذكاء الخلية.
- بداية الإدخال الشامل.
- النطاقات المتعددة.
- نطاق العمليات الشاملة.
- ألوان التنسيق المقترحة.
- خريطة الحقول كمساعدة في لصق/استيراد البيانات.

لا يقوم تحليل السياق بالكتابة في ملف Excel؛ هو طبقة قراءة واقتراح فقط.
