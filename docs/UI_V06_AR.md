# واجهة v0.6 العربية

تمت إضافة تبويب **الذكاء والإدخال الشامل** إلى واجهة v0.5.

## ذكاء الخلية
حدد الورقة والخلية ثم **تحليل الخلية**. يعرض:
- نوع الخلية.
- الصيغة إن وجدت.
- القيمة المخزنة.
- نوع البيانات والخطأ إن وجد.
- المراجع المباشرة والخلايا المتأثرة عبر Trace.

## الإدخال الشامل
يمكنك:
1. تحديد الورقة.
2. تحديد خلية بداية النطاق مثل `F11`.
3. لصق جدول كامل من Excel عبر TAB/CSV.
4. أو استيراد CSV/TSV/XLSX/XLSM للقراءة.
5. الضغط على **معاينة التغييرات** لرؤية القديم والجديد.
6. الضغط على **تنفيذ الإدخال الشامل** لإنشاء نسخة جديدة.

افتراضيًا، الخانات الفارغة **لا تمسح** البيانات الموجودة. يمكن تفعيل خيار **المربعات الفارغة تمسح البيانات الحالية** عندما يكون المسح مقصودًا.

بعد التنفيذ، يفتح البرنامج Excel ويحدد أول خلية من النطاق المعدل بصريًا.

## نطاقات متعددة
يمكن توزيع الإدخال على أكثر من بلوك دون لمس الصفوف الفاصلة. مثال:
```powershell
-ranges "F11:I70;F76:I135;F141:I200;F206:I265;F271:I330"
```
ويتم توزيع الصفوف المدخلة بالتسلسل على هذه النطاقات. الخانات الفارغة لا تمسح البيانات افتراضيًا إلا مع خيار المسح.
