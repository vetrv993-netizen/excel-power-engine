# v0.7 — محرك العمليات الشاملة

## ما الجديد
1. البحث الذكي عن كلمات أو أجزاء كلمات أو Regex في القيم والصيغ.
2. Target Engine يدعم خلية، نطاق، نطاقات متعددة، صفوف، وأعمدة.
3. تنسيق جماعي: تعبئة، خط، غامق، التفاف، تنسيق أرقام.
4. حدود جماعية.
5. دمج وإلغاء دمج.
6. إعداد الطباعة.
7. تصدير PDF عبر Excel Native.
8. Workflow يربط عدة عمليات في عملية واحدة مع نسخة احتياطية.

## ملاحظة السلامة
العمليات التي تحتاج Excel Native تعمل على نسخة ناتجة وليس على المصدر مباشرة. بعد الحفظ يحاول المحرك إعادة `xl/vbaProject.bin` الأصلي إذا تغير، ثم يفحص وجود `x14`.

## قاعدة العمل
بحث → تحديد أهداف → معاينة → Backup → تنفيذ → تحقق → مشاهدة بصرية داخل Excel.
